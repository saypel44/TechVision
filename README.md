# Tech Vision Website

## Files
- `index.html` — Main HTML structure
- `style.css`  — All styles and responsive layout
- `script.js`  — Nav toggle and scroll-active logic

## Setup
1. Place your logo file named exactly `logo.png` in the same folder as `index.html`
2. Open `index.html` in a browser

## Logo usage
The logo appears in two places:
- **Nav bar** — 36×36px (top left)
- **Hero section** — 80×80px (center brand lockup)

Both reference `logo.png` via `<img src="logo.png">` so just drop your file in and it works.
